# PLP Python Week 8 - My Young Hero

## Project Description
My Python Toolkit is a simple menu-driven Python program with three tools: a Number Guessing Game, a To-Do List, and a Simple Calculator. The project demonstrates Python loops, lists, conditionals, functions, input handling, and f-strings.

## Tools
1. **Number Guessing Game** - Guess the secret number until you get it right.
2. **To-Do List** - Add, view, and remove tasks.
3. **Simple Calculator** - Perform addition, subtraction, multiplication, and division.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

bash
python toolkit.py
